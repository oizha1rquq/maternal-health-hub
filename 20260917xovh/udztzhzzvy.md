# 加速推进互联网医院建设，抢占医疗服务模式创新制高点

> 更新时间：2026-09-17 (UTC+8)

家住昌平的吴女士是一位高血压患者，行动不便但需要定期随访和取药，每次她都要赶到北京朝阳医院复诊，颇为麻烦。在得知朝阳医院互联网医院开通在线复诊服务功能后，吴女士在家使用朝阳健康云APP预约了心内科的在线复诊号。心内科在线复诊的医生详细询问吴女士症状，根据既往病历，为她开具了药品处方及检查医嘱。短短十分钟，吴女士就完成了挂号、复诊、开具在线医嘱的流程。“不用再费时费力跑医院，在家就能咨询医生、开到药，第一次体验到网上看病原来这么方便！”

图一、门诊大厅互联网医院服务台实景图
2021年4月2日，北京朝阳医院顺利通过北京市卫生健康委员会互联网医院专家组评审，成为北京市第四家获得互联网医院资质的三甲医院。此次评审的顺利通过，是对北京朝阳医院前期作为北京市互联网试点医院工作的充分肯定。

图二、互联网医院评审会后合影
在推进朝阳医院互联网医院的建设过程中，医院坚持科技创新和制度创新“双轮驱动”，以化解就医难题为导向，以满足患者需求为牵引，全面主导互联网医院服务流程设计、技术开发等各个环节，以“严谨、创新、关爱、奉献”的朝阳精神，打造“有温度的朝阳医院互联网医院”。

北京朝阳医院自2013年开始探索基于移动互联网的各类别应用，以业务系统和数据结构的优化为起点，以移动APP应用为载体，为患者、医护、管理者赋能。疫情期间，北京朝阳医院按下互联网医院建设的“快进键”，在北京市范围内率先上线“免费咨询”服务。2020年3月6日，医院取得“互联网诊疗”资质， 2020年3月31日，“互联网诊疗”业务正式上线，2020年4月30日，朝阳医院互联网医院正式获批成为北京市6家试点医院之一；2020年5月8日医院取得互联网+医保定点医疗机构资质，实现互联网诊疗医事服务费的实时分解。

图三、互联网医院医生出诊场景
截至目前，医院共计上线呼吸科、心内科、内分泌科、消化内科、神经内科、风湿免疫科、肾内科、泌尿外科等19个科室263医生，科室为互联网医院配置了优质医师资源，出诊医师均为高职称、高年资、经验丰富的临床医师，在提供在线诊疗服务的医生中，副高及以上职称占比超过70%。患者可通过视频、声音、文字、图片等方式与专家“面对面”交流，目前已累计完成近万人次的在线复诊的服务、开具处方5000余张。

北京朝阳医院在推进互联网诊疗工作的过程中，注重发挥综合医院学科完备的优势，推进医疗、护理、药事等多学科互联网诊疗工作的协同发展，为患者提供全方位的互联网医疗服务。

在互联网医院的运营过程中，医院将数据驱动服务创新放在突出位置，充分发挥互联网诊疗全数字化的优势，对诊疗过程进行精准质控，提升医患双方满意度，同时医院将保护患者隐私放在突出位置，在医疗服务不断向外延伸的同时，做到诊疗数据不出医院。下一步医院将继续加强医疗服务模式创新，加大互联网医疗服务供给，为广大患者提供更为便捷的就医途径，让人民群众有更多获得感和幸福感。
