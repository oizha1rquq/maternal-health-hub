# 常捏脊，宝宝长得壮

> 更新时间：2026-09-11 (UTC+8)

钧妈发现现在的娃生活的真是幸福啊，各种精致的养，为了让孩子能茁壮成长，老父亲老母亲们简直是操碎了心。

生孩子之前，疲惫的下班的时候，总想去按摩一下，放松下筋骨。按完整个人都舒服了，现在按摩椅在各大商场的风行也是看中了现在人缺乏锻炼、需要疏通筋骨这个市场。

小孩子年纪小，自然是不能像我们大人一样那么按了，但是他们也可以接受家长在家里对他们进行的捏脊，这对他们的生长发育有很多好处哦。

为什么要捏脊？

捏脊是民间传下来的一种治病强生的方法，人体背部的正中为督脉，督脉的两侧为足太阳膀胱经的循行路线。通过捏脊疗法，可以疏通经络，达到调整脏腑的作用。

捏脊可以用来治疗多种小儿疾病，以治疗小儿消化不良效果最好。捏脊疗法能调理宝宝脾胃，使之正常运转，脾胃功能正常了，宝宝就不会积食、腹胀、腹痛的现象，睡觉会更踏实。

当宝宝患反复感冒、咳嗽等肺部疾病时，也可以通过捏脊进行一定的调理。通过捏脊还可以刺激宝宝脊柱两侧的自主神经干和神经节，起到防遗尿、止汗的作用。

捏脊要注意什么？

1. 在早晨起床后或晚上临睡前进行捏脊，疗效更好，捏脊前要露出整个背部，力求背部平、正，让肌肉放松；

2. 捏脊时室内温度要适中，妈妈要将指甲修整光滑，可将适量的按摩油或者护肤乳倒在手上，双手搓热再为宝宝捏脊；

3. 每次捏脊时间不宜过长，3-5分钟即可；

4. 捏脊适合半岁到七岁的宝宝，过小的播报皮肤娇嫩，掌握不好力度容易造成皮肤破损；年纪过大的孩子则因为背肌较厚，不易提起，穴位点按不到位会影响效果；

5. 如果宝宝的背部皮肤有破损、皮肤病等则不能进行捏脊。

怎么捏脊？

让宝宝趴在床上，家长双手手指弯曲，成半握拳式，大拇指和食指、中指相对，将皮肤捏起。从下腰部沿脊椎由下往上捏，直到平肩的位置为止，可随捏、随拿、随推、随放。

反复做3遍为一次，第一遍的手法应该是很轻柔的；第二遍的手法就要稍微重些，每捏两下后将皮肤往上提一下；捏完第三遍后，再用两掌的大鱼际，由下向上揉三遍。一般每天捏一次，消化不好的宝宝可以连续捏7-10天为一疗程。效果不明显，可连续做两个疗程。

开始捏时手法要轻柔，而后逐渐加重，使宝宝慢慢适应。要捏准，不可拧转。拿捏推进时，要直线向前，不可歪斜。用力及速度要均等，捏脊中途最好不要停止。

但是捏脊虽好，也要讲究正确的方法和时机，做不对的话，可能会没作用；同样，捏脊也不是多多益善，每天一次即可，家长切不可贪心每天捏个十几次遍或者早上捏完晚上还要捏，长期坚持反倒会对宝宝造成伤害。
